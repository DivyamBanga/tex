    02How it works
    1. Upload

      Drop in your ChatGPT or Claude HTML export. Cortex parses every message from every conversation.

      parsers/chatgpt_parser.py
    2. Embed

      Each conversation is summarized and embedded into a 768-dimensional vector, locally, through Ollama.

      nomic-embed-text · 768d
    3. Reduce

      UMAP folds 768 dimensions into 3 and keeps the neighbourhoods intact, so things that are close in meaning stay close in space.

      UMAP · 768 → 3
    4. Cluster

      K-Means groups the cloud into topics and gives each one a semantic name. Your interests show up as constellations.

      K-Means · k=5
    5. Recall

      Claude calls into your memory mid-conversation over MCP, so it already has the context and you don't paste anything.

      search_memory · fetch_chat
